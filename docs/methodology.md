# 평판등급(준비 중) 산정 방법 — v1

Offorby의 평판등급은 **인터넷에서 그 사람에 대해 오간 말의 분위기**를 100점 점수와 10단계 등급으로 요약한 것입니다. 사람이 손으로 매기지 않으며, 아래 절차가 매일 자동으로 돌아갑니다. 이 숫자는 정치인의 능력이나 도덕성에 대한 평가가 아니라, 최근 온라인 여론의 방향을 보여주는 지표입니다.

## 1. 무엇을 보나
세 곳에서 그 사람의 이름이 들어간 글을 모읍니다.

| 출처 | 보는 것 | 비중 |
|---|---|---|
| 뉴스(Google News) | 기사 제목 | 50% |
| 유튜브 | 이름으로 검색된 영상의 댓글 | 30% |
| 커뮤니티(디시인사이드 정치 관련 갤러리) | 글 제목 | 20% |

글 본문이나 댓글 원문은 판정 직후 지우고 저장하지 않습니다. 남기는 것은 건수와 판정 결과뿐입니다.

## 2. 어떻게 판정하나
모은 글 하나하나를 AI(Claude)가 읽고 세 가지를 답합니다.
- 이 글이 **정말 그 사람 얘기인가** (이름만 스쳐간 글은 제외)
- 분위기가 **긍정 / 중립 / 부정** 중 무엇인가
- 그 **강도**는 1(약함)~3(강함) 중 어느 정도인가

출처별로 하루 최대 50건까지만 판정합니다.

## 3. 어떻게 점수로 만드나
1. **출처별 순감성** = (긍정 − 부정) ÷ (긍정 + 중립 + 부정). 강도가 셀수록 더 크게 반영합니다.
2. **최근일수록 무겁게**. 최근 28일만 보고, 14일 지날 때마다 영향이 절반으로 줄어듭니다.
3. **표본이 적으면 50점 쪽으로 당깁니다.** 글이 몇 건 안 되는 사람이 우연히 극단값을 받지 않도록, 분모에 20건 상당을 더합니다. 20건이면 원래 비율의 절반만 반영되고, 수백 건이면 거의 그대로 반영됩니다.
4. 출처별 순감성을 위 비중으로 합칩니다. 글이 없는 출처는 빼고 나머지 비중을 다시 100%로 맞춥니다.
5. **점수 = 50 + 50 × 합산 순감성**. 모두 중립이면 50점, 모두 긍정이면 100점에 가까워집니다.

## 4. 등급
점수를 10점 단위 절대 구간으로 나눕니다. 다른 사람과의 비교가 아니라 점수 자체로 정해집니다.

| 등급 | 점수 |
|---|---|
| 1등급 | 90~100 |
| 2등급 | 80~89 |
| 3등급 | 70~79 |
| 4등급 | 60~69 |
| 5등급 | 50~59 |
| 6등급 | 40~49 |
| 7등급 | 30~39 |
| 8등급 | 20~29 |
| 9등급 | 10~19 |
| 10등급 | 0~9 |

28일 동안 판정된 글이 **10건 미만**이면 점수·등급을 내지 않고 "데이터 부족"으로 표시합니다.

## 5. 한계
- 뉴스 제목은 정치인끼리의 공방이 많아 "A가 B를 비판"이라는 제목이 B의 부정으로 집계됩니다. 뉴스 비중을 절반으로 둔 이유 중 하나입니다.
- 유튜브 댓글은 영상 주제와 무관한 글이 많습니다. AI가 "그 사람 얘기가 아님"으로 걸러내지만 완벽하지 않습니다.
- 커뮤니티는 정치 관련 갤러리 네 곳만 봅니다. 특정 성향이 과대 대표될 수 있어 비중을 가장 낮게 뒀습니다.
- 동명이인은 구분하지 못합니다.
- 방법은 바뀔 수 있으며, 바뀌면 이 문서와 `method_version`을 함께 올립니다.

## 6. 데이터
- 수집·판정 코드와 이 문서는 모두 공개 저장소에 있습니다.
- 저장하는 것: 인물별·출처별·일별 긍정/중립/부정 건수, 점수, 등급, 뉴스 기사 제목과 링크.
- 저장하지 않는 것: 댓글·게시글 원문, 작성자 정보.
