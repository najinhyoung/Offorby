## 걸린 문제와 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| `.cmd` 실행 시 `'rlevel'은(는)…` 같은 토막 오류 | 파일이 UTF-8 한글인데 cmd.exe는 CP949로 읽음 | **.cmd는 ASCII(영문)만** 쓰기 |
| `and은(는) 예상되지 않았습니다` | `if ( … )` 블록 안 echo에 괄호 | 블록 안 문장에서 괄호 제거 |
| PowerShell에서 스크립트 실행 안 됨 | 현재 폴더 실행은 `.\` 필요 | `cmd /c scripts\x.cmd` 또는 `.\scripts\x.cmd` |
| 서비스계정 키 발급 `FAILED_PRECONDITION` | 새 프로젝트가 **조직 255490325030** 아래 생성 → `iam.disableServiceAccountKeyCreation` 기본 적용(구 프로젝트는 조직 밖) | 본인에게 조직 수준 `roles/orgpolicy.policyAdmin` 부여 → `gcloud org-policies reset iam.disableServiceAccountKeyCreation --project=offorby` → 1~2분 전파 후 키 발급 |
| `bq` CLI `UnicodeDecodeError: cp949` | 한글 사용자 폴더 경로 | `$env:PYTHONUTF8='1'` 후 실행 |
| PowerShell 파이프로 `bq query`에 SQL 전달 시 `Illegal input character "\357"` | BOM | Python 클라이언트로 조회 |
| Claude 자동 모드가 IAM 부여·조직 정책 해제 차단 | 보안 완화 분류 | 해당 명령은 사용자가 직접 실행 |
