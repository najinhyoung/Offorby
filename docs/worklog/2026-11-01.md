## 삽질 기록 (다음에 참고)
- gcloud: PowerShell 실행 정책 때문에 `gcloud.ps1` 막힘 → `gcloud.cmd` 사용
- gcloud ADC 로그인 때 동의 화면에서 권한 체크 빠지면 `cloud-platform scope ... not consented` → 다시 로그인하며 모두 체크
- BigQuery 결제 미연결(샌드박스)이면 DML 불가 + 테이블 60일 만료 → 결제 연결 필수
- BigQuery 리전: 클라이언트에 `location` 명시 안 하면 US로 돌아 DDL과 충돌
- 결제 계정 통화가 KRW → 예산도 KRW로 만들어야 함
- 열린국회 API: Python 기본 User-Agent는 400 → UA 헤더 지정
- Actions는 UTC → 날짜 KST 기준으로 계산
- Claude Code에서 IAM 권한 부여 명령은 자동 차단됨 → `scripts/grant_writer.cmd`로 사용자가 직접 실행
